# Kharcha Tracker

A pocket-money expense tracker for hostel life: add what you spent, see this month's total, and watch which category quietly eats your money.

**Try it:** open `index.html` in any browser. No account, no server — data is saved in your own browser (localStorage).

## What it does

- Add an expense with a name, amount (₹) and category (Food, Travel, Study, Shopping, Recharge, Other)
- Live totals: this month, all time, and number of entries
- A per-category bar chart that updates as you add
- Delete any entry, or clear everything
- Data persists between visits on the same browser

## Why I built this

Hostel pocket money disappears in ₹40 and ₹60 pieces — canteen, auto, printouts — and at month end nobody knows where it went. I wanted the smallest possible tracker: no sign-up, no app install, open the page and type. It is also how I practise keeping honest numbers, the same habit my startup runs on.

Plain HTML, CSS and JavaScript in a single file.
